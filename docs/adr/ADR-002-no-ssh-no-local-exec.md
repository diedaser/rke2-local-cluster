# ADR-002: No SSH, no local-exec, no host tools

- **Status:** Accepted, 2026-10-16

## Context

The meshStack runner is an ephemeral container with no guaranteed binaries and no network path to the nodes over SSH.

## Decision

Modules never use `ssh`, `kubectl`, the `helm` CLI, `curl`, `remote-exec`, `local-exec`, `null_resource` with shell, or `external` data sources. Node configuration happens only through cloud-init. Cluster interaction happens only through providers (`http`, `helm`, `kubernetes`, `rancher2`).

## Consequences

- Plans are deterministic and run in any runner.
- OpenTofu cannot read files back from nodes, so the cluster PKI is generated by OpenTofu ([ADR-003](ADR-003-opentofu-generated-pki.md)).
- `scripts/validate-all.sh` fails on `local-exec`, `remote-exec` and `data "external"`.
- The nodes themselves still download the RKE2 install script (`rke2_install_script_url`). That runs on the node, not in the runner.
