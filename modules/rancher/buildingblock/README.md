# `rancher` building block

Installs cert-manager and Rancher on the cluster created by `rke2-cluster`,
bootstraps the admin account, and stores the admin credentials in AWS Secrets
Manager. Cluster access comes from the kubeconfig the parent stored in Secrets
Manager.

Executed by the meshStack building block runner. See the repository
[README](../../../README.md), [CONTRIBUTING.md](../../../CONTRIBUTING.md) and the
[meshStack definition](../meshstack/definition.md).

The tables below are generated by terraform-docs. Do not edit them by hand:

```bash
terraform-docs -c .terraform-docs.yml modules/rancher/buildingblock
```
